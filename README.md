22 da Giu — Desafios 

Site de desafios da festa com ranking em tempo real usando Supabase. 

Arquivos 

index.html: app pronto para publicar no GitHub Pages 

supabase.sql: SQL para criar tabelas e liberar acesso público para a festa 

Publicação rápida 

No Supabase, abra o SQL Editor e rode o conteúdo de supabase.sql. 

No GitHub, envie index.html para a raiz do repositório. 

Em Settings > Pages, publique a branch main na pasta /root. 

Aguarde o link do GitHub Pages ficar ativo.
